AI 早报 11月19日｜爱尔兰监管让 X 停用智能体收集的他人数据训练 AI

一句话总结：今天最重要的是，爱尔兰隐私监管机构让 X 停下了一件事：不再用 Grok Bot 智能体收集来的“别人的数据”训练 AI。

今天讲四件事。

第一件，是隐私和规则。据 Politico 报道，爱尔兰数据保护委员会周一确认，X 已经暂停这项处理。按报道的说法，X 从十月底开始，把 Grok Bot 智能体接触和收集到的第三方数据拿去训练模型。第三方数据，指的是关于别人的个人信息，比如朋友发给你的旅行照片，你的智能体看到了；或者智能体从网上抓来的内容。监管机构说有“重大担忧”，要求暂停，X 已照办。监管方还说，正在和另一家没点名的公司谈同样的计划。

为什么重要？以前隐私争议主要是“用我自己的数据训练”，现在焦点转到智能体替你办事时顺带看到的别人的信息。欧洲监管已经开始管这一层。

第二件，是大公司的新产品。微软在 Ignite 大会上推出 Autopilot，一个一直在线的个人智能体，开始给早期体验的企业客户推送。它能盯着 Teams 频道、跟进邮件、跑定期任务，不用每次等你开口。微软强调的是管控：每个 Autopilot 有自己的身份，有一位指定的负责人；它登录和做的每件事都记在自己名下，安全团队能查；管理员能限制权限，随时封掉。刚启用时，它先读过去三十天的邮件、会议和文件来熟悉情况，这一步不发送、不修改任何东西。关键操作前可以设成先问你。

为什么重要？“没人说话时助手自己干活”正在变成主流产品。微软给出的答案是：主动可以，但身份要独立，记录要在助手外面。

第三件，是智能体的新做法：从接任务，变成管目标。Cognition 推出 Devin Bots，一个长期在线、有自己记忆的智能体，负责一个目标，再指挥多个 Devin 去干活。公司举例说，一个机器人用四十四天几乎独立做出了安卓版应用，合并了一千一百多个代码改动，工程师一共只发了一百八十多条消息，多半是回答需要人拍板的问题。同一天，Replit 推出 Missions：开工前先签一份约定，写明目标、成功标准、花钱上限、哪些动作要你批准；另有一个独立的 AI 评审按标准检查结果，钱花完了就停。这些数字都是公司自己说的，没有第三方核实。

为什么重要？两家都在回答同一个问题：智能体能长期自主干活时，人怎么只管关键决定。答案很像：先约定标准和预算，再派一个独立检查者。

第四件，是安全上的小改进。Anthropic 推出关联计费测试版。以前在第三方工具里用 Claude，常常要把 API 密钥交出去，这把密钥就像密码，谁拿到都能用你的钱调用。现在改成授权关联：不交密钥，你给每个平台设每月花费上限，随时可以解除。要注意一点：请求在平台那边运行，所以你自己账号里的数据保留等设置管不到。另外，Claude Code 新版本允许从标准输入读取 MCP 服务器配置，这样令牌，也就是登录凭证，不会留在命令行记录里。

为什么重要？“不交钥匙，只给有上限的授权”，正在成为智能体接入第三方服务的标准做法。

以上就是今天的 AI 早报。
