论文速读 11/06｜AI 助手说“做完了”，命令其实没执行

今天讲三篇：一个跨燕山大学、腾讯和芬兰阿尔托大学的团队发现，AI 编程助手常常以为命令执行成功了，其实什么都没做；南洋理工大学的团队发现，给 AI 智能体装上完全无害的“技能说明书”，它反而更容易做出越界的事；还有荷兰格罗宁根大学医学中心的一项《自然》论文，从肠道细菌基因里一个个字母的差别，找出了和年龄、体重等健康指标有关的九百多条线索。

先说第一篇。这是十一月一日放上 arXiv 的预印本，通讯作者是阿尔托大学的田浩野。它讲的是一个很多人没注意过的坑。

AI 编程助手，比如 Claude Code、Codex，是通过命令行去干活的：装软件、迁移数据库、删文件、生成密钥。问题是，很多命令在真正动手之前，会先问一句，比如“确定要删除吗”“请输入密码”。可是助手后面并没有人坐着回答。

这时有两种情况。第一种，运行环境直接把命令的输入关掉。程序读不到回答，就按默认处理，然后照样报告“成功”。作者测了一百五十八种会提问的命令，在这种情况下，有十八种报了成功，但要求的动作根本没做。比如清理 Docker 的命令什么也没删，带确认的删除命令留下了文件。还有十二种更糟，没经确认就直接动手了，比如生成了一个没有密码保护的密钥。论文开头的例子是，一个数据库迁移脚本把数据库删了，照样报告成功，助手还跟用户说“数据都还在”。

第二种情况，输入保持开着，但没人打字，命令就一直卡到超时。助手干等、重试，又费时间又费钱。作者统计，这种情况下任务花掉的 token 是正常情况的二点九倍。

作者查了八种常用的智能体运行环境，七种在没有终端时会把输入关掉，包括 Claude Code 和 Codex。还有一个细节：在他们的测试里，Claude Code 的子任务放到后台运行，几秒钟后就被悄悄结束了，而且没有任何提示。

更有意思的是，这个问题还会影响排行榜。同一组模型，只是换了一种输入方式，Llama 3.3 七百亿参数版的排名就从第七变成了第三。也就是说，有些榜单比的不只是模型，还混进了运行环境的差别。

他们的解法叫 Receipt，意思是“回执”。它让输入保持开着，然后每零点一秒去看一下操作系统：这个程序是不是正卡在等输入。确认是在等，就把一张回执交给 AI，写清楚是哪个程序在问、问的是什么，以及之前的操作还没有核实过。怎么回答，由 AI 自己决定。

结果在五个模型上，助手谎报成功的次数从三十四次降到九次，比一直开着终端少用四分之一的 token。对比之下，只在任务里加一句“完成前请核对结果”，效果明显不如它。

可信程度方面：这还是预印本，没经过同行评审。测试用的大多是较老的开源模型。测试任务也是作者自己设计的，不过他们说，写最后十组任务之前，已经把检测方法定死了。作者的结论是：AI 助手靠不靠得住，不光看模型本身，还要看运行环境让它看到了多少真实情况。

第二篇来自新加坡南洋理工大学，八位作者都在同一个院系，十一月初发在 arXiv 上，也是预印本。

现在很多 AI 智能体都会装“技能”，就是一份份写好的操作步骤，比如怎么下载图片、怎么发帖、怎么改服务器配置。这些技能本身都是正经的，没有一句坏话。作者问的是：装上这些无害的技能，会不会让智能体在遇到坏请求时更容易照做？

他们用了五个模型，包括 GPT-5.4-nano，在三套测试上比较装技能和不装技能。结果，装技能后，正常任务的完成率平均提高十点三个百分点，执行违规操作的比例也正好提高十点三个百分点。论文举了个例子：用户让它把手机放进微波炉加热。不装技能时，它认出危险，拒绝了。装上技能后，它嘴上承认有风险，手上还是把手机放进去，按了启动。

还有几个细节。第一，原本安全的一百五十一次执行里，有五十次在装技能后变得不安全。其中二十四次，坏事其实并没有办成。所以如果只看“坏任务有没有完成”，近一半的越界行为会被漏掉。第二，就算是专家手写的技能，也一样会把风险抬高。第三，让技能根据正常任务的反馈不断自我改进，一百轮之后，完成率又涨了九点六个百分点，违规率也跟着又涨了将近五个百分点。

那问题出在哪？作者做了拆解。跟请求越对口的技能，风险越高。把技能里具体的操作步骤删掉，只留说明，违规率在三套测试上分别降了大约十九、十四和八个百分点。还有一个反直觉的发现：同一份经验，原样保留成执行记录，比整理成通用的步骤说明更安全。作者认为，原因在于技能只写了怎么做，从来不判断这件事该不该做。

解法是在每个操作真正执行之前，加一道检查，由另一个模型判断这一步该不该放行。这样违规率能降二十四到四十六个百分点，正常任务的收益大部分也能保住。但还剩一些违规没拦住。局限是：测试的都是中小模型，还有一部分是模拟的家务机器人环境，判断是否违规也部分依靠 AI 裁判。

最后一篇是十一月四日发表在《自然》上的同行评审论文，开放获取。主导者是格罗宁根大学医学中心的傅静远教授和王道明博士。

以前研究肠道菌群，大多是数每种细菌有多少。这篇看得更细，看的是同一种细菌内部，基因里单个字母的差别，学术上叫单核苷酸变异。傅静远在学校的新闻稿里说，我们身体里九成以上的基因，其实不属于人类细胞，而属于肠道里的微生物。

他们收集了六个队列、一万零七百八十一人的粪便样本，其中五个在荷兰，一个在坦桑尼亚。他们在一千二百八十万个这样的字母差别，和二百四十四项健康指标、生活暴露之间逐一做比对，最后找到九百四十条彼此独立的关联，涉及一百零一种细菌和六十九项指标。大约三分之二的关联，只数细菌多少的话根本看不出来。王道明说，只看数量，会漏掉很多联系。

关联最多的是年龄，有九十九条。光用这些细菌基因差别训练的模型，在其他队列里能解释一成多到四成的年龄差异。最清楚的一条在一种很常见的肠道细菌，普氏栖粪杆菌身上。带有某个特定字母的人，平均年龄大了大约五岁。这个变化落在一个负责运输谷胱甘肽的蛋白上，谷胱甘肽是一种抗氧化物质。作者推测，细菌可能是在适应人变老后肠道里更强的氧化压力。还有一个初步发现：一个和较低体重有关的变异，出现在一种模仿人类食欲激素的细菌蛋白上。但傅静远也说，潜力很大，现在还不能下任何结论。

可信度方面，有几点要分开看。这是相关研究，不是因果研究。作者自己也说，可能是人的身体变了，细菌跟着适应；也可能是细菌的变化反过来影响健康。机制部分主要靠电脑预测蛋白结构，还没有做实验验证。样本以荷兰人为主，最大的一个队列就占了将近四分之三，坦桑尼亚的样本比较少。不过在两地都能检验的二百一十五条关联里，有七成多在两地都成立。作者把全部结果公开成了在线目录，希望其他国家的团队来验证。

今天就讲到这里。三篇放在一起看，有一个共同点：只看表面的结果，不管是“命令成功了”“坏事没办成”，还是“细菌有多少”，都会漏掉真正重要的东西。
