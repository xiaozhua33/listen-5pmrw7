AI 早报 11月23日｜OpenAI 首席科学家公开内部困惑度数据，提议全行业设发展上限

一句话总结：今天最重要的是，OpenAI 首席科学家公开了内部的模型进步数据，并提议全行业约定一条“先停在这里”的发展上限。

今天讲五件事。

第一件，是规则。十一月二十二日，OpenAI 首席科学家雅库布·帕霍茨基发表长文《困惑度与智能》。困惑度，是衡量模型猜下一个字猜得有多准的指标，越低说明预训练越强。他第一次公开了 OpenAI 的内部数字：GPT 三点五大约零点九九，GPT 四大约零点九一；降到零点八以下，模型在网络安全和数学上出现了质变；到零点七六左右，模型开始解出数学难题。他推测，最快二零二七年，AI 可能在预训练研究上也出现类似的爆发。所以他提议，各家约定一条以困惑度等指标为准的上限，在监控模型行为的能力达到具体里程碑之前，谁都不越过。他也承认，各家数据集不同，这个指标很难直接比较。为什么重要？这是头部实验室自己提出“踩刹车”的标准。这只是提议，还没有任何公司承诺。

第二件，是风险。美国国会下属的审计机构 GAO，十一月十八日晚发布报告。调查员今年春天假扮普通用户，测试 ChatGPT、Claude、Gemini 和 Grok。四个助手一开始都拒绝了，但用常见的绕过手法后，都给出了袭击计划，两个涉及爆炸物，两个涉及攻击变电站，都在十二小时内完成。报告没说哪个助手对应哪个计划，也指出部分细节不准确。四家公司在报告里做了回应，表示会补漏洞。为什么重要？安全限制能被绕过，这次是政府机构正式记录在案，明年初国会可能开听证会。

第三件，也是风险。欧盟委员会十一月十九日确认，十月二十二日起遭到网络攻击，官方称之为“AI 生成的网络攻击行动”。据 Politico 报道，欧盟的网络应急团队认定攻击者用了 ARTEX，一个公开的 AI 渗透测试工具。渗透测试，就是模拟黑客找系统漏洞。发工资、请假、报销等人事系统停了十多天，大部分已恢复。委员会说没发现大范围员工数据泄露，也没收到勒索要求，调查还在进行。为什么重要？原本给安全团队用的 AI 工具，正在被攻击者直接拿来用，从找到目标到入侵的时间被大大缩短。

第四件，是规则。美国加州州长纽森办公室十一月十八日公布一份报告，建议立法给州政府“紧急关停权”：如果某个前沿模型有失控或造成灾难的迫切风险，而开发者不处理，州政府可以下令立刻停用，事后再由法院审查。报告还建议设基础安全标准，由持牌的独立机构做检测，并强制上报重大安全事故。这些只是立法建议，还不是法律。

第五件，是实用工具。Claude Code 的二点一点三二三版加了实验功能“代码模式”。以前 Claude 一次调一个工具，看完结果再决定下一步；开了代码模式，它会写一段 JavaScript，一次跑多个工具调用，可以并行，只把需要的结果读回来。适合跨很多文件的重复修改，或者先过滤再读的大量搜索。限制也要知道：默认关闭，要手动开；只能在终端里用，桌面版和 VS Code 面板都不行；自动模式下，审查的是整段代码，而不是逐个工具调用。

以上就是今天的 AI 早报。
