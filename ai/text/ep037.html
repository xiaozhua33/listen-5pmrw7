AI 早报 11/11｜Claude 开始进会议室了

一句话总结：今天最重要的是，Anthropic 让 Claude 以参会者身份进到谷歌会议里，一边听讨论，一边做计划、开始干活。

今天讲四件事。

第一件，是大公司的新产品。Anthropic 十一月十日发布了 Claude Meetings。Claude 作为看得见的参会者加入 Google Meet，能在会议聊天里回答问题，从连上的工作应用里调资料，讨论时就做出计划和时间表，会后留下笔记和待办。目前是测试版，只给团队版和企业版。同一天，交互式连接器也升级了：Notion、Asana、Dropbox 等工具可以在 Claude 旁边整页打开，用你自己的账号；你让 Claude 改哪一页、哪一行，它改的时候你能实时看到。底层是 MCP Apps，一个让 MCP 服务器带上自己界面的开放扩展。

为什么重要？助手正从聊天框走进会议和工具本身，MCP 也不再只是给模型调用的接口了。

第二件，是风险。谷歌 DeepMind 十一月九日发了一份关于提示注入的技术报告。提示注入，就是藏在网页、邮件或工具结果里的一句话，骗智能体做用户没要求的事。人工测试里，新模型几乎都挡得住，看起来快解决了。研究者造了一个更强的攻击者：十六个智能体分组合作，共享笔记，反复试探。结果七个被测模型全被攻破过。最强的 Gemini 4 Argon，最多只挡住百分之六十六的场景；几个开放权重模型只挡住百分之一。

限制也要说清：测试关掉了产品里的外部防护，攻击目标都是无害操作，数据和代码没公开，也没经过同行评审。另一篇十月的论文还发现，同一句恶意指令放在 README 这类说明文档里，比放在代码里更容易被照做。

为什么重要？不能只靠模型自己守规矩，防线要放在模型外面，比如审批、沙盒和权限限制。

第三件，是实用工具。自动化工具 n8n 的实验团队推出了 Nod，一个装在自己电脑上的开源个人智能体。它在本机虚拟机里有自己的浏览器，能连邮箱、日历、Slack，也能操作没有接口的网站，比如退订阅、盯价格。模型用你自己的。安全设计是重点：发送、付款、删除之前，有一个单独的检查确认是你要求的，网页和邮件不能给它下命令；密码和银行卡在本机加密，模型看不到；每个任务显示花费，超过五美元先问你。官方也承认，这个检查本身是模型，会出错。

为什么重要？个人智能体的标准配置越来越清楚：独立电脑、外部内容只当资料、敏感操作单独确认、花费看得见。

第四件，是规则。美国纽约州十一月十日开放了注册入口。按 RAISE 法案，年收入超过五亿美元的前沿模型公司，比如 OpenAI 和 Anthropic，要在明年一月一日前注册，公开安全框架，重大安全事故七十二小时内上报。违规一次最高罚一百万美元。

为什么重要？它管的是模型公司，不直接管用户；但事故要上报，以后关于模型出问题的真实信息会更多。

今天就到这里，明天见。
