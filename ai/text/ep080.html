AI 早报 11月25日｜MCP 满两周年，服务器可以自带技能和后台长任务

一句话总结：今天最重要的是，MCP 满两周年，Claude 让 MCP 服务器可以直接附带技能，还能把长任务放到后台跑。

今天讲五件事。

第一件，是智能体的新做法。11月24日，Anthropic 在 MCP 两周年时宣布了三项更新。第一，Skills over MCP 进入公开测试。以前 MCP 服务器只告诉 Claude 有哪些工具，现在可以把怎么用的技能一起带上，比如 Shopify 带上整套开店流程。技能只在需要时才加载，占用的上下文很少，而且跟着服务器一起更新，用户不用另外安装。第二，Tasks 正式上线，服务器可以在后台跑耗时很长的操作，Claude 先干别的，结果好了再取回来。第三，Elicitation 也正式上线，服务器在花钱、删数据这类动作前，可以停下来弹出表单，让用户确认后再继续。比如 GitHub 要求用户先手动输入仓库名，智能体才能删除这个仓库。文件上传功能也快要推出了。为什么重要？连接器正在从“一组工具”变成“带说明书、会请示的小助手”。

第二件，是大公司新产品。Claude 桌面版推出“安装成应用”测试功能，Mac 和 Windows 都能用。你在聊天里描述一个小工具，比如菜单栏里的番茄钟，Claude 做好后点一下就能装成独立应用，有自己的窗口和图标。你明确允许的话，它还能运行程序、读文件、发通知。打开时必须联网并登录 Claude。另外，Claude 把技能、连接器和插件合并到了一个插件页面里，团队版从11月30日开始切换。为什么重要？做个人小工具的门槛又低了一截，但权限给多少要自己把关。

第三件，是安全工具。OpenAI 和思科一起开源了一个叫 Shirudo 的 Linux 安全平台。它用 eBPF，也就是一种能在系统内核里安全运行小程序的技术，在不重启的情况下，给正在运行的系统打上针对性的“临时补丁”，把有漏洞的那段代码路径挡住，给团队争取时间去做正式修复。这些补丁带数字签名，由内核验证后才加载。为什么重要？AI 让找漏洞变快了，防守方也开始用同样的速度来补。

第四件，是规则。11月24日，纽约州州长霍楚尔签署法律，五年内禁止在纽约制造、销售内置 AI 聊天机器人的儿童玩具，比如会聊天的毛绒玩具和机器人。法律签署九十天后生效，每次违规每天最高罚一万五千美元。起因是消费者组织测试发现，有的玩具会和孩子深入聊色情话题，还会告诉孩子家里哪里可能找到火柴；聊得越久，安全限制越弱。为什么重要？这是美国州一级第一次直接按“产品类别”禁止一类 AI 产品。

第五件，也是规则。美国弗吉尼亚州和俄勒冈州的总检察长，11月23日分别起诉 SpaceX 和旗下的 AI 公司，指控 Grok 让用户用真人照片生成未经同意的色情图片，其中还涉及儿童，同时公司又对外宣称自己有安全措施。两州用的是消费者保护法，要求禁令、退还非法所得和罚款。公司回应说，这类内容在 X 和 Grok 上没有立足之地，安全措施一直在更新。这是第一次由州政府出面起诉，案子才刚开始。

以上就是今天的 AI 早报。
