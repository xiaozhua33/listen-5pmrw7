AI 早报 11/06｜AI 助手开始替人打电话了

一句话总结：今天最重要的是，AI 助手开始替人打电话了，Grok Bot 的电话功能已经上线。

今天讲四件事。

第一件，是助手的新做法。十一月四日，Grok Bot 官方账号在 X 上宣布，它可以替用户打电话了。拨号之前，它先弹出一张卡片，写明要打给谁，用户点了才打。通话中能看实时文字记录，对方问到助手答不上的问题，用户可以打字告诉它，也可以随时接管或挂断，结束后在聊天里汇报结果。按多家媒体报道，目前只能打美国号码，助手要告诉对方自己是虚拟助理；服务条款写明，用户是法律上的来电人，要为每通电话负责。也有商家一发现是 AI，就不肯办理账户变更。

为什么重要？智能体第一次伸手到电话这种老渠道，而且是先确认、再执行、随时可接管，这套设计值得留意。

第二件，是亚马逊云的新产品。十一月五日，AWS 在它的开源多智能体开发环境 Kiro Crew 里正式推出 Kiro 机器人。每个机器人负责一块固定的工作，比如分拣问题单、盯构建结果，有自己的名字、指令、工具和权限。它能同时派出好几个干活的智能体，盯着进度，跑偏了就拉回来，最后汇总结果；需要人拍板时先来问，不相关的活接着干。每个机器人还有一份叫 Notes 的长期笔记，记下偏好、做过的决定和限制，人可以查看、修改、删除。也能在聊天里设定定时任务，比如每个工作日早上查夜里失败的构建。分析师提醒两点：多个智能体在后台重试、调工具，算力花费会叠加；权限会越要越多，人容易习惯性点同意。

为什么重要？一个总管带多个专门助手，各有记忆和定时任务，这种结构正在变成大厂认可的标准做法。

第三件，是 Anthropic 的新功能。十一月五日，Claude 推出个人理财工具，通过一家叫 Plaid 的金融数据公司连接银行和信用卡账户。你可以问这个月钱花哪去了，它按类别汇总，还会指出重复扣款、意外手续费和越涨越高的账单。Anthropic 强调只读，不能转账也不能投资；它能看到的是余额、额度和最多两年的交易记录，在理财页面里的对话不拿去训练模型。目前只在美国，先给付费用户测试。

为什么重要？助手开始碰最敏感的数据，只读、能看到哪些数据，会成为连接器的基本说明。

第四件，是安全研究。安全公司 Glow Labs 发现，用户只说一句帮我装个 GitHub 的 MCP，写代码的智能体就凭训练时记住的名字，装上 Anthropic 早年发布、现在已经停止维护的示范版 MCP 服务器，而不是 GitHub 官方的那个。在他们看到的这类情况里，百分之九十八是智能体凭记忆自己选的，Claude Code、Cursor、Codex 命令行工具都出现过。这批旧服务器里有四个高危漏洞，最严重的在一个让智能体开浏览器的服务器上：有人在网页里埋一段提示词注入，就能让智能体在电脑上执行任意命令。维护方已经说不会修。研究方也说，目前还没看到有人真的利用。

为什么重要？模型记住的软件名字可能早就过时了，装 MCP 之前，要确认是不是官方版、是不是还在维护。

今天就到这里，明天见。
